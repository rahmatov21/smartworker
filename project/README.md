# AI Pipeline Target Project

This directory contains the target project codebase that the autonomous self-improving agent continuously inspects, benchmarks, enhances, and tests.

## Architecture
- `src/ai_pipeline.py`: Core text tokenization, TF vectorization, and cosine similarity search engine.
- `tests/test_ai_pipeline.py`: Unit test coverage verified before every change.
- `benchmarks/benchmark_pipeline.py`: Automated benchmark to evaluate search latency and throughput.
